# 选择器与弹窗触摸开发

这些功能包含在 codex-touch v0.3.0 中，仍固定 Codex 0.169.0。独立包为 `~/codex-touch-build/packages/touch-pickers-0.169.0`。2026-11-18 用户确认手机测试通过，并授权将其设为开发手机的日用启动目标；v0.2.0 Release 和旧包保留。

## 覆盖清单

| 界面 | 适配 |
| --- | --- |
| 恢复和分叉 | 先点会话选中，再点已选中行打开。backend/thread 标识防止列表变化后打开错行。工具栏筛选、活动/归档、排序，以及密度、预览、展开、取消和可见导航提示复用原动作。 |
| 通用列表弹窗 | 实际绘制行、换行条目、标签及溢出导航、页脚、展开说明与滚动。禁用项保持禁用，选中后接受沿用各弹窗规则；包括模型、配置、审批、验证、快捷键选择等共用菜单。 |
| 设置和多选 | 技能、实验功能、记忆设置、状态栏/标题字段、应用链接和 hooks。分节标题不会被当作可选项。 |
| 同步问答与 MCP 表单 | 选项、确认项、备注/文本输入及操作提示，保留原答案提交、校验、自动处理、排队与权限流程。 |
| 文本/提供商/按键编辑 | 自定义提示与反馈输入框、提供商字段及 Save、按键捕获取消和调试器关闭；按键记录仍走原逻辑。 |
| 补全弹窗 | 命令、文件、技能、提及标签/行；触摸执行 Tab 补全，不直接提交命令。 |

| 记录与静态分页器 | 可见导航、搜索、选择/复制、关闭等界面生成的提示；原记录鼠标选择仍保留，搜索内容不是动作。 |
| 警告与统计 | 页脚动作，保留原警告策略和统计控件。 |
| 启动选择 | 工作目录、更新、模型迁移、取消归档、外部配置迁移、hook 检查、恢复和草稿输入。 |
| 初始设置 | 登录模式和目录信任行；继续、返回、上下、下一字段、退出和可用复制动作的触摸导航条。目录信任仍需明确确认；云提供商/gateway 表单通过导航条切换字段。 |
| 其他提示 | `/keymap customize`、双 Esc 编辑、合并的子代理切换提示、侧边会话确认页脚。主帮助中仅供参考的记录动作需要先打开记录，在其当前页脚点击操作。 |

点按指左键按下并在未拖动时释放。针对各视图的事件流程处理缩放、目标变化、键盘输入、失焦及界面切换，取消过期手势。命中几何来自绘制，不解析终端缓冲区或模型输出来执行动作。要求默认全屏模式及 `CODEX_TOUCH=1`。

## 手机验收

进入日用客户端相同的 Debian 环境后运行：

```sh
bash /storage/emulated/0/Agent/codex-touch/scripts/run-touch.sh resume
```

1. 点未选中会话，再点一次恢复；拖过行不应打开。在 `/fork` 中重复。
2. 点击可见筛选/排序/状态控件及页脚，包括记录预览、取消；折叠/展开或调整大小后再试。
3. 尝试 `/model`、设置多选和确认弹窗；逐步明确确认，检查禁用行无动作。
4. 点按补全斜杠命令或文件提及，然后另行提交。打开帮助并点击快捷键自定义，确认草稿保留。
5. 在可用时测试浮动组合键提示、记录导航/搜索、同步问答及 MCP 表单；确认键盘仍可使用，触摸不穿透弹窗。

自动化不能证明所有手机交互和外部提供商流程。2026-11-18 用户报告手机测试通过；此处记录用户验收结果，不推断已经逐一验证所有外部提供商流程。自动呼出 Android 键盘、`--no-alt-screen`、此前异步多题卡住报告与答案编辑器便捷换行不在本次修改范围。

历史搜索适配可见的接受/取消后缀，排除可编辑查询内容。两项更新弹窗快照从上游占位版本 0.0.0 修正为固定包版本 0.169.0。云恢复测试只筛选实际回答行，避免含“response”的随机启动提示干扰断言。
