# codex-touch v0.2.0

首个功能版本，为 Termux 中的 Codex 0.169.0 增加触摸操作。本次发布源码，可在手机的 Debian ARM64 环境中构建适配客户端。

## 主要功能

- 点击异步问答摘要与答案，编辑 Other/自由文本，点击提交、跳过与前后题提示。
- 点击主输入区和快捷键帮助中的换行、模式、推理强度等动作，支持运行时两段绑定；有草稿时保留帮助和换行入口。
- 在 Agent command center 中点选/打开任务，操作筛选、分组、底部提示和帮助动作。
- 点击完整显示的 `esc to interrupt` 提示中断运行中的回合。
- 拖动、裁剪、布局/焦点变化或弹层覆盖时取消点按，保留上游动作与确认流程。
- 全项目默认文档使用英文，保留简体中文版本，每份文档顶部均提供语言切换链接。

## 构建与运行

目标为 `aarch64-unknown-linux-gnu`（glibc），已在由 Termux 提供终端的 Debian chroot 中验证。按[构建指南](../build.zh-CN.md)安装依赖与 Rust 1.95.0，然后执行：

```sh
git clone --branch v0.2.0 --depth 1 https://github.com/Zircon10086/codex-touch.git
cd codex-touch
bash scripts/check.sh
bash scripts/build-touch.sh
bash scripts/run-touch.sh
```

启动器通过 `CODEX_TOUCH=1` 启用触摸，不改变 HOME/CODEX_HOME；在同一 Linux 用户环境下默认共用日用 Codex 的配置与会话。包内 Codex 版本仍为 0.169.0，0.2.0 是 codex-touch 适配项目版本。

## 附件

- `codex-touch-0.2.0-source.tar.gz`：仓库源码、补丁、脚本、许可证与双语文档，不含 Git 元数据或构建缓存。
- `SHA256SUMS`：上述源码归档的 SHA-256。
- GitHub 也提供自动生成的源码归档，它们的字节内容与上述附件不同，不在 `SHA256SUMS` 校验范围内。

将两个具名附件下载到同一目录后，执行 `sha256sum -c SHA256SUMS`。归档是源码分发，不是预编译客户端。构建脚本可从解压目录运行；仓库检查额外要求 Git checkout。本次 Release 没有预编译二进制附件。

## 验证

本次未修改的触摸补丁已在功能开发期间通过 409 项去重 Rust 回归、隔离工具调用/程序包检查、SGR 鼠标 PTY 和终端恢复检查。用户真机验证了主要异步问答路径及 command center/中断修复。本次更新文档和版本信息，没有改变这些 Rust 行为；发布检查覆盖仓库一致性、双语文档与链接、精确补丁匹配和源码归档。

## 已知限制

- 仅覆盖默认全屏 TUI，`--no-alt-screen` 尚不在适配范围。
- 普通同步问答、其他确认弹窗及部分合并快捷键参考行尚未适配。
- Android 键盘仍需手动打开，自动显示 IME 未实现。
- 异步答案编辑器的便捷换行入口和曾报告的多题卡住问题仍待处理。
- 其他 Termux 渠道、proot 和其他架构尚未完成同等验证。
