# codex-touch v0.3.0

0.3.0 为“Resume a previous session”界面补齐触摸，并扩展菜单、弹窗、补全列表和导航提示的点击功能。仍基于 Codex 0.169.0，可全部在手机的 Debian ARM64 环境内构建，由 Termux 提供终端。

## 主要变化

- 恢复/分叉列表支持选中、打开会话，点击筛选、排序、活动/归档、密度、预览、展开和取消。稳定会话标识及手势取消防止过期行误触。
- 通用列表、设置/多选、审批、同步问答、MCP 表单、提供商字段和启动/初始设置导航支持触摸，保留原有校验与确认流程。
- 点击命令/文件/技能/提及补全，插入选中内容，另行提交。
- 补齐浮动组合键/预设指引、记录和分页器、历史搜索接受/取消、警告与统计提示、快捷键自定义和合并的子代理导航提示。
- 保留 v0.2.0 的异步问答、主输入、Agent command center 和中断触摸；继续处理拖动、截断、缩放、过期状态及视图覆盖。
- 今后确认更新版本时默认同步发布对应 GitHub Release，除非明确要求暂缓；已写入项目约定和开发指南。

完整范围见[覆盖与验收记录](../picker-touch.zh-CN.md)。

## 构建和运行

目标为 `aarch64-unknown-linux-gnu`（glibc），已在 Debian chroot 与 Termux 环境验证。按[手机构建指南](../build.zh-CN.md)安装依赖及固定 Rust 1.95.0 后执行：

```sh
git clone --branch v0.3.0 --depth 1 https://github.com/Zircon10086/codex-touch.git
cd codex-touch
bash scripts/check.sh
bash scripts/build-touch.sh
bash scripts/run-touch.sh resume
```

默认包为 `~/codex-touch-build/packages/touch-pickers-0.169.0`，脚本拒绝覆盖已有包；再次构建时通过 `CODEX_TOUCH_PACKAGE` 指定新路径。启动器设置 `CODEX_TOUCH=1`，保留 HOME/CODEX_HOME，因此正常启动时与同一 Linux 用户的日用 Codex 共用配置和会话。

上游 CLI 仍显示 `codex-cli 0.169.0`，**0.3.0** 是 codex-touch 适配版本。开发手机已通过固定 `crcodex` 启动器使用验收后的包；发布此版本无需重新编译相同二进制。

## 附件

- `codex-touch-0.3.0-source.tar.gz`：仓库源码、累计补丁、脚本、许可证及双语文档，不含 Git 元数据、凭据或构建缓存。
- `SHA256SUMS`：上述指定源码包的 SHA-256。

将两个文件下载到同一目录后运行 `sha256sum -c SHA256SUMS`。GitHub 自动生成的源码归档字节不同，不包含在该校验文件中。本次不附预编译客户端。构建脚本可从解包源码运行，仓库检查另外要求 Git checkout。

## 验证

所含 Rust 补丁已通过 43 组筛选条件下的 1,297 项去重回归、程序包/辅助程序和 app-server 检查、本机假模型/工具回合及默认 daemon TUI 检查。扩展 SGR 鼠标 PTY 耗时 49.8 秒通过，包含恢复筛选/预览/打开、直接启动恢复、补全、弹窗取消、快捷键自定义及终端恢复。日用固定启动器另在清除继承的 `CODEX_TOUCH` 后通过扩展 PTY，耗时 55.0 秒。

用户于 2026-11-18 确认手机测试通过。本次发布修改版本、文档和发布说明检查，Rust 补丁及已安装二进制与已验收构建一致；上述 Rust/PTY 数据沿用功能开发和部署时的记录，不表示本次重新执行。发布检查验证仓库一致性、双语链接、补丁精确匹配、归档内容及公开附件完整性。

## 已知限制

- 仅支持默认全屏 TUI，`--no-alt-screen` 不在适配范围。
- Android 软键盘仍需手动打开，尚未实现自动呼出。
- 主帮助中部分记录动作仅供参考，需要打开记录后使用当前控件；云/gateway 初始设置表单通过触摸导航条切换字段。
- 异步答案编辑器便捷换行与此前报告的多题卡住问题仍待后续处理。
- 其他 Termux 渠道、proot、其他架构及全部外部提供商流程尚未完成同等验收。
