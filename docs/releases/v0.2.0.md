# codex-touch v0.2.0

The first functional codex-touch release adds touch controls to Codex 0.169.0 in Termux. It is a source release for building an adapted client in Debian ARM64 on a phone.

## Highlights

- Tap asynchronous question summaries and answers, use Other/freeform editing, and tap submit, skip, and navigation hints.
- Tap main-composer and shortcut-help actions, including newline, mode, reasoning effort, and runtime two-key bindings. Help and newline remain available with a draft.
- Select/open tasks and use filters, grouping, footer hints, and help actions in Agent command center.
- Tap the fully visible `esc to interrupt` hint to interrupt a running turn.
- Cancel taps on dragging, clipping, layout/focus changes, or view coverage, while preserving upstream action and confirmation flows.
- Use English default documentation throughout the project, with Simplified Chinese versions and language links at the top of every document.

## Build and run

The target is `aarch64-unknown-linux-gnu` (glibc), tested in Debian chroot with Termux providing the terminal. Install dependencies and Rust 1.95.0 using the [build guide](../build.md), then:

```sh
git clone --branch v0.2.0 --depth 1 https://github.com/Zircon10086/codex-touch.git
cd codex-touch
bash scripts/check.sh
bash scripts/build-touch.sh
bash scripts/run-touch.sh
```

Touch is enabled by the launcher through `CODEX_TOUCH=1`. It leaves HOME/CODEX_HOME unchanged and normally shares configuration and sessions with regular Codex in the same Linux user environment. The package's Codex version remains 0.169.0; 0.2.0 identifies the codex-touch adaptation.

## Assets

- `codex-touch-0.2.0-source.tar.gz`: repository source, patch, scripts, licenses, and both documentation languages, without Git metadata or build caches.
- `SHA256SUMS`: SHA-256 for that source archive.
- GitHub also provides its automatically generated source archives. Their bytes differ from the named archive and are not covered by `SHA256SUMS`.

After downloading both named files into the same directory, run `sha256sum -c SHA256SUMS`. The archive is a source distribution, not a prebuilt client. The build scripts can run from an extracted archive; repository checks additionally require a Git checkout. No prebuilt binary is attached to this release.

## Validation

The unchanged touch patch passed 409 distinct Rust regressions, isolated tool-call/package checks, SGR mouse PTY checks, and terminal restoration checks during feature development. On-device testing confirmed the main asynchronous question paths and the command center/interrupt fixes. This release adds documentation and versioning; it does not change those Rust behaviors. Release checks cover repository consistency, bilingual documentation and links, exact patch matching, and the exported source archive.

## Known limits

- Default full-screen TUI only; `--no-alt-screen` is outside current touch coverage.
- Synchronous question dialogs, unrelated confirmation dialogs, and some combined shortcut reference entries are not adapted.
- Open the Android keyboard manually. Automatic IME display is not implemented.
- A convenient newline control in the asynchronous answer editor and a reported multi-question stall remain follow-up work.
- Other Termux channels, proot, and other architectures have not received equivalent validation.
